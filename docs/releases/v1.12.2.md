# YTN 1.12.2

A maintenance update. No new NAS features or changes to your saved servers are included.

- The compose file editor (Apps › app › Edit compose) now checks YAML with SnakeYAML Engine 3.2.
- It's stricter about mapping keys: a key must be plain text, so list- or map-shaped keys (like `? [a, b]`) are flagged as an error before anything is sent to the NAS.
- New tests cover the editor's YAML checks: duplicate keys, error positions, aliases and their limit, multi-line commands, comments and formatting.
- Added verified checksums for the updated library.

## Downloads

- `truenas-companion-release.apk`: phone/tablet app; installs over the existing release.
- `truenas-companion-debug.apk`: separate YTN Preview phone app.
- `truenas-companion-wear-release.apk`: Wear OS companion; update separately with `adb install -r`.

Each APK has a matching `.sha256` file. Existing signing identities are preserved.
