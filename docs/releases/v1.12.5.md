# YTN 1.12.5

## Temperature on the watch

Thanks for testing 1.12.4 in #12! Alerts, CPU and RAM showed up on the watch, but the temperature didn't on TrueNAS 27.

- The watch now reads the current disk temperatures straight from the NAS, the same way the phone's dashboard does. This works on TrueNAS 25.10 and 27.
- If that's not available, it uses the NAS's temperature history from the last 30 minutes.
- If no disk reports a temperature at all (for example virtual disks), the watch shows the CPU temperature instead, next to the CPU usage: *CPU 16%, 45 °C · RAM 50%*.
- Disks that report "no reading" no longer hide the temperature of the others. This also fixes phone alert rules like "disk stayed above X °C", which could miss hot disks for the same reason.

Install 1.12.5 on **both** the phone and the watch. An older watch app keeps working with the new phone app, but it won't show the CPU temperature fallback.

TrueNAS 27 is still a release candidate, and this hasn't been tested on a real 27 system yet.

## Downloads

- `truenas-companion-release.apk`: phone/tablet app; installs over the existing release.
- `truenas-companion-debug.apk`: separate YTN Preview phone app.
- `truenas-companion-wear-release.apk`: Wear OS companion; update separately with `adb install -r`.

Each APK has a matching `.sha256` file. Existing signing identities are preserved.
