# YTN 1.12.3

## The watch app now connects

Thanks for the report in #12! Since 1.12.0 the Wear OS app kept saying *Not set up*, even with YTN open on the phone. The release builds were accidentally stripped of the small tag that lets the phone and the watch find each other. It's back in both apps, and a check now guards it in every build.

- Install 1.12.3 on **both** the phone and the watch, then open YTN on the phone once. The watch gets your NAS status right away.
- Refreshing from the watch no longer gets dropped when YTN on the phone was closed.

## TrueNAS 27 containers (experimental)

TrueNAS 27 replaces the old Incus containers with a new container system. YTN now detects which one your NAS uses and works with both:

- List your containers with their status, CPU pinning, memory, autostart and pool.
- Start, stop, restart and delete (stopped containers only, and it asks first; snapshots are kept).
- Open a shell in a running container.

TrueNAS 27 is still a release candidate, and this hasn't been tested on a real 27 system yet, so please treat it as experimental and report anything odd. Nothing changes on TrueNAS 25.10.

## Downloads

- `truenas-companion-release.apk`: phone/tablet app; installs over the existing release.
- `truenas-companion-debug.apk`: separate YTN Preview phone app.
- `truenas-companion-wear-release.apk`: Wear OS companion; update separately with `adb install -r`.

Each APK has a matching `.sha256` file. Existing signing identities are preserved.
