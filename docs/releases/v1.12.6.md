# YTN 1.12.6

## Under the hood

A maintenance release with updated build tools and libraries. There are no new features or visible changes.

- Android Gradle plugin 9.5.1 (was 9.4.1).
- AndroidX DataStore 1.3.0 (was 1.2.1), the library that stores YTN's settings. Your existing settings carry over unchanged.
- Roborazzi 1.78.0 (was 1.76.0), used only by the screenshot tests.
- GitHub Actions `setup-java` 6.3.0 for the CI build.

Every new library file is checked against its published checksum before the build uses it.

Install 1.12.6 on the phone and, if you use it, on the watch too, so both stay on the same version.

## Downloads

- `truenas-companion-release.apk`: phone/tablet app; installs over the existing release.
- `truenas-companion-debug.apk`: separate YTN Preview phone app.
- `truenas-companion-wear-release.apk`: Wear OS companion; update separately with `adb install -r`.

Each APK has a matching `.sha256` file. Existing signing identities are preserved.
